# circuit-onboarding

The invoice-triage workflow used in the GraphMind Circuit guide.

From the repo root:

```sh
pnpm install
pnpm circuit:demo   # guided walkthrough, nothing to set up
pnpm circuit:dev    # dev server on http://127.0.0.1:4810/v1 to drive yourself
```

Full guide: [`docs/circuit/USAGE.md`](../../docs/circuit/USAGE.md).
