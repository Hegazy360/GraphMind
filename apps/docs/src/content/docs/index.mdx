## What you can actually do

<CardGrid>
  <Card title="Pause on error" icon="warning">
    Armed by default. The first time a tool throws, the agent stops *in place* — arguments,
    partial state and stack still live — instead of leaving you a trace to read afterwards.
  </Card>
  <Card title="Breakpoints & step mode" icon="setting">
    Break before any node by kind or name, or step every boundary. Held gates are indefinite:
    nothing is in flight while you think.
  </Card>
  <Card title="Inject and continue" icon="random">
    Replace a tool's result — or a failure — with a value you type, and let the agent keep
    running on it. Test the recovery path without touching your code.
  </Card>
  <Card title="Fails open, always" icon="approve-check">
    No debugger attached? Instrumentation is a no-op. Debugger disconnects mid-hold? Every gate
    auto-continues. Your production path never waits on a viewer.
  </Card>
</CardGrid>
